# Tarefa 06 — Árvore Binária de Busca (ABB)

## Objetivo
Implementar uma Árvore Binária de Busca com classes para árvore, nós e registros; oferecer inserção, remoção, busca e percursos; e utilizar a ABB como índice para localizar registros armazenados em arquivo.

## Organização
- `src/`: implementação da ABB e da aplicação de indexação.
- `tests/`: testes de inserção, busca, remoção, percursos e operações sobre arquivos.
- `data/`: arquivos pequenos de exemplo para desenvolvimento.
- `relatorio/`: relatório de análise crítica e post-mortem da IA.

## Executar
Preencher este README com os comandos reais assim que os módulos principais forem implementados.

## Checklist
- [ ] Classe de registro e definição da chave de ordenação
- [ ] Nó e classe ABB independentes
- [ ] Inserção, busca e remoção
- [ ] Percursos em pré-ordem, em ordem, pós-ordem, largura e profundidade
- [ ] Índice associado às posições dos registros no arquivo
- [ ] Exclusão lógica de registros sem deslocar as demais linhas
- [ ] Mais de um índice para campos diferentes e tratamento de chaves repetidas
- [ ] Testes e análise de complexidade
- [ ] Relatório e post-mortem da IA
