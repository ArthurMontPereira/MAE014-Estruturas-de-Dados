# Tarefa 08 — Tabela Hash

## Objetivo
Implementar uma tabela Hash configurável, com funções de dispersão e estratégias de resolução de colisões, e utilizá-la para eliminar duplicatas de um dataset CSV.

## Organização
- `src/`: implementação da tabela Hash e da aplicação de deduplicação.
- `tests/`: testes de inserção, busca, remoção, colisões e duplicatas.
- `data/`: arquivos pequenos de exemplo para desenvolvimento.
- `relatorio/`: relatório de análise crítica e post-mortem da IA.

## Executar
Preencher este README com os comandos reais assim que os módulos principais forem implementados.

## Checklist
- [ ] Definir o tipo de chave e o critério de duplicidade
- [ ] Implementar funções de Hash configuráveis
- [ ] Implementar estratégias de resolução de colisões escolhidas pelo grupo
- [ ] Inserção, busca e remoção por chave
- [ ] Deduplicação do CSV escolhido
- [ ] Comparar quantidade de registros antes e depois
- [ ] Testar colisões, chaves repetidas e remoções
- [ ] Analisar complexidade e limitações
- [ ] Relatório e post-mortem da IA
