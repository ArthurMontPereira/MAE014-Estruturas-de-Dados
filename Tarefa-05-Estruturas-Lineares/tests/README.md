# Testes da Tarefa 05

Coloque aqui os testes automatizados de cada estrutura e aplicação.

A suíte deve verificar não apenas os caminhos comuns, mas também estrutura vazia, limites de posição, chaves inexistentes e repetidas, operações em extremidades, estabilidade da ordenação e atualizações das aplicações.

Use a biblioteca `unittest` ou outra ferramenta escolhida pelo grupo. Documente no README principal da tarefa o comando real de execução e registre a saída dos testes no relatório.
