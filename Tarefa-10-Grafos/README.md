# Tarefa 10 — Grafos, Dígrafos, Multigrafos e Hipergrafos

## Objetivo
Desenvolver uma hierarquia para representar grafos, dígrafos, multigrafos e hipergrafos; estudar formas de armazenamento; e testar BFS, DFS e menor caminho nas aplicações escolhidas pelo grupo.

## Organização
- `src/`: classes, representações, algoritmos e aplicações.
- `tests/`: testes das estruturas, conversões/representações e algoritmos.
- `data/`: exemplos pequenos de grafos e entradas para as aplicações.
- `relatorio/`: relatório de análise crítica e post-mortem da IA.

## Executar
Preencher este README com os comandos reais assim que os módulos principais forem implementados.

## Checklist
- [ ] Definir interfaces comuns e subclasses
- [ ] Implementar as representações escolhidas (lista de arestas, lista/matriz de adjacência e/ou matriz de incidência)
- [ ] Representar corretamente direção, laços e arestas paralelas
- [ ] Definir representação e operações de hipergrafo
- [ ] Implementar BFS e DFS
- [ ] Implementar menor caminho para o exemplo de mapa (por exemplo, Dijkstra)
- [ ] Desenvolver as aplicações escolhidas pelo grupo
- [ ] Comparar tempo e espaço das representações
- [ ] Testar casos isolados, desconexos, ciclos, laços e arestas paralelas
- [ ] Relatório e post-mortem da IA
